# SWATrust tutorial

This tutorial shows, step by step, how to run SWAT+ models with SWATrust, from the first start to the reading of the results.

SWATrust runs a SWAT+ model, which is one folder of text files with a file named `file.cio` in it, from a page in the web browser of your own computer. Each chapter gives the steps for one task, with the reason for each step. Where a chapter has a video, the video stands at the end of the chapter and shows the same steps.

## Where to start

- If SWATrust is new to you, start with the [Quick start](quick-start.md). It uses one basin, 02070002 (North Branch Potomac).- If SWAT+ itself is new to you, watch the film on SWAT+ in [Get to know SWATrust](about.md) first.
- If you have a SWAT+ model of your own, read [Run your own model](own-model.md) after the quick start.
- If you want the flow of a basin over the years you choose, go to [Run streamflow](run-streamflow.md).
